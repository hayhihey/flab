# Ridehub - Brand Guidelines

## 🎯 Brand Identity

### Mission
To revolutionize mobility by providing intelligent, real-time ride solutions that connect people seamlessly across cities.

### Vision
Become the world's most trusted smart mobility platform with AI-powered routing, sustainable practices, and community-driven innovation.

### Core Values
- **Smart** - Intelligent technology at every step
- **Transparent** - Clear pricing, fair practices
- **Reliable** - Consistent, on-time service
- **Inclusive** - Accessible to everyone
- **Sustainable** - Eco-friendly operations

## 🎨 Visual Identity

### Logo
The RideHub logo combines:
- **Map Pin**: Navigation and location intelligence
- **Path/Route**: Journey and continuous movement
- **Gradient Colors**: Modern, dynamic energy

#### Logo Usage
- Minimum size: 32px (web), 40px (mobile)
- Clear space: At least 8px around logo
- Always use on contrasting backgrounds
- Never stretch, rotate, or modify colors

#### Font Families
- **Display**: Plus Jakarta Sans (headings, calls-to-action)
- **Body**: Inter (body text, UI labels)

#### Type Scale
```

Title: 28px (Semibold)
Subtitle: 20px (Semibold)
Body Large: 16px (Regular)
Body: 14px (Regular)
Label: 12px (Medium)
```

### Iconography
- **Icon Library**: Lucide React Icons
- **Size Grid**: 16px, 20px, 24px, 32px, 40px
- **Stroke Width**: 2px for most icons
- **Color**: Inherit from context (primary, accent, or white)

## 🎬 Motion & Animation

### Animation Principles
- **Duration**: 200-300ms for most interactions
- **Easing**: cubic-bezier(0.4, 0, 0.6, 1) for smooth motion
- **Purpose**: Enhance, don't distract

### Common Animations
```
Fade In:       opacity 0 → 1 (300ms)
Slide Up:      translateY 20px → 0 (300ms)
Scale:         scale 0.95 → 1 (300ms)
Glow:          shadow pulse effect (infinite)
Float:         translateY -10px oscillation (6s)
```

## 🌐 Web Presence

### Application Screens

#### Authentication
- Clean, minimal design
- Hero gradient background
- Prominent CTA buttons
- Progress indicators for multi-step flows

#### Dashboard
- Card-based layout
- Quick stats overview
- Recent activity feed
- Quick action buttons

#### Maps & Navigation
- Full-width interactive map
- Bottom sheet for ride details
- Real-time location markers
- Clear pickup/dropoff indicators

### UI Components

#### Buttons
- **Primary**: Indigo gradient, full width on mobile
- **Secondary**: Ghost style, outlined borders
- **Danger**: Red background, clear warning
- **Disabled**: Reduced opacity, no interaction

#### Cards
- Rounded corners (12-16px)
- Subtle shadow
- Hover states with slight lift
- Border: 1px solid with primary/10 opacity

#### Forms
- Clear labels and placeholders
- 44px minimum touch target
- Inline error messages
- Success states with checkmarks

## 📱 Mobile-First Design

### Touch Targets
- Minimum 44px × 44px for interactive elements
- Safe area margins on notched devices
- Thumb-friendly layout zones

### Responsive Behavior
- Stacked layout on mobile (single column)
- Two-column grid on tablet
- Three+ column grid on desktop
- Flexible typography scaling

## ♿ Accessibility

### WCAG 2.1 AA Compliance
- Color contrast ratio: 4.5:1 for text
- Focus states: Clear 2px outline
- Semantic HTML: Proper heading hierarchy
- ARIA labels: For complex components
- Keyboard navigation: Full support

### Dark Mode
- Default: Dark theme (#020617 background)
- High contrast: Excellent for low-light usage
- Color blindness: Avoid red-only indicators

## 📊 Data Visualization

### Charts & Graphs
- Clean, minimal design

- Clear axis labels
- Legend placement: Bottom or right

### Icons & Illustrations
- Consistent style
- Simple, recognizable shapes

## 🚫 Brand Do's & Don'ts

### Do's ✅
- Use official logo and colors
- Maintain consistent spacing
- Follow typography guidelines
- Use appropriate contrast ratios
- Keep designs simple and clean

### Don'ts ❌
- Don't modify logo colors or proportions
- Don't use old branding materials
- Don't apply filters to official assets
- Don't place on busy backgrounds
- Don't use unpermitted fonts
